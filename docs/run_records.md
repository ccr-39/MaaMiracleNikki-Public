# 单次队列内存记录

一次“开始任务”创建一个 `RunState`，本轮所有勾选任务共享它。单个任务结束不清空，
同轮的内部恢复仍可读取已完成状态和未确认交易，避免重复点击购买。
全部任务结束、队列失败退出或用户停止时，`TaskRuntime.close()` 清空所有记录；
下一次启动创建空白记录，不继承上一轮。

服装店购买状态、织梦人购物金额及待确认交易、谜之屋金币抽取计数均保存在内存中。
记录名称沿用旧文件名仅作为内存键；正式运行不创建 JSON、临时文件或交易锁文件。
不读取头像设置中的数字账号，不生成账号标识，不上传记录。

旧文件读写只作为明确传入 `Path` 时的兼容接口供离线测试使用，正式入口全部传入
`RunRecord`。旧本地账号记录不加载。运行中切换账号应先停止当前队列，再开始新一轮。

清零后不能依靠旧计数防止下一次手动启动再次购买；任务仍读取当前游戏页面判断状态。
程序异常退出时内存记录也会消失，不支持跨进程恢复未确认交易。
