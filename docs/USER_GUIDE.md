# MMN 中文新手教程

适用于 Windows 10/11 x64。当前提供 v0.1.2-rc.1 公开 Pre-release，可从 GitHub Release 下载完整 Windows ZIP；发布状态见[发布说明](PUBLIC_RELEASE_STATUS.md)。MMN 是非官方《奇迹暖暖》日常自动化工具，与游戏运营方无关联。自动化可能违反游戏服务条款，导致账号限制或资源损失；游戏更新可能使识别失效。请先阅读 [README 的功能、风险与许可证](../README.md)，自行决定是否使用。

## 1. 下载、校验与解压

1. 打开[公开测试版下载页面](https://github.com/ccr-39/MaaMiracleNikki-Public/releases/tag/v0.1.2-rc.1)，无需申请仓库访问权限。下载完整 Windows ZIP，不要下载自动生成的 Source code 作为运行包。
2. 下载 Windows x64 ZIP 及同名 `.sha256`。本版文件名为 `MaaMiracleNikki-Windows-x64.zip`；`Source code` 不是可直接运行的程序。
3. 在资源管理器中打开保存 ZIP 的下载文件夹（解压前的 ZIP 所在位置），点击地址栏输入 `powershell` 并按回车。在打开的 PowerShell 中执行下方命令；它只读取 ZIP，不启动程序。命令中的 `.\` 表示当前文件夹；如 ZIP 已改名，请使用实际文件名。用记事本打开下载的 `.sha256`，将其中的 SHA256 与命令输出的 `Hash` 比较，应完全一致（忽略大小写）；不一致时先重新下载，不要运行。
4. 完整解压到可写目录，如 `D:\Apps\MMN`。打开解压后的 `MaaMiracleNikki` 文件夹，双击 `MaaMiracleNikki.exe`；不要在 ZIP 内启动，不要只提取 EXE。保留相邻 `_internal`、`MMNUpdater.exe`、`mmn-update.json` 和所有随包说明。无需安装 Python、Node 或 CMD 启动器。

校验命令（在上述下载文件夹的 PowerShell 中执行）：

```powershell
Get-FileHash .\MaaMiracleNikki-Windows-x64.zip -Algorithm SHA256
```

普通用户无需逐个下载 Release 中其余 16 个第三方对应源码及许可附件，运行所需文件和许可说明已在 Windows ZIP 内。

MMN 不含游戏、模拟器和 ADB。请使用模拟器自带的 ADB；第三方来源和素材说明必须随程序保留。系统提示时先核对下载来源和哈希，不要盲目关闭安全软件。

## 2. 首次启动与配置位置

首次运行会在 **EXE 所在文件夹**生成 `userdata\config\gui.json`，并在 `userdata` 下记录本次日志。全新安装的默认值如下：

| 项目 | 默认值 |
| --- | --- |
| 14 个正式任务组 | 全部不勾选 |
| ADB 地址、ADB 路径、模拟器路径与启动参数 | 空；ADB 路径留空时仅在需要时查找 |
| 自动连接、每日定时、自动启动模拟器、完成后关闭模拟器 | 全部关闭 |
| 定时时刻 | 08:00，仅预设，未启用 |
| 保存上次勾选 | 开启 |
| 任务失败后继续、离线演练 | 关闭 |
| 启动后自动检查更新 | 开启，仅查询稳定版；可在软件更新中关闭 |
| 补签、好友邮件、图书馆三次整理、评选赛参赛、额外金币抽取 | 关闭 |
| 评选赛投票、体力处理件数 | 20 次、4 件；仅勾选相应任务后执行 |

设置修改约 400ms 后自动保存，看到“已自动保存”后再退出。保存失败时检查文件夹权限及磁盘空间，可用“重试保存”。各安装目录独立，重开同一目录会保留设置，不会自动导入其他目录或共享 LocalAppData 的个人配置。

## 3. 配置模拟器与 ADB

1. 自行安装 Android 模拟器及《奇迹暖暖》国服中文客户端，手动启动模拟器、登录游戏、处理验证码并进入可操作页面。当前识别主要适配竖屏 **900×1600**，部分流程按 720×1280 参考坐标缩放；其他分辨率、主题和缩放不能保证可用。
2. 在模拟器设置中开启 ADB 调试，按模拟器要求重启。ADB 端口和多开编号以该实例实际设置为准，不能直接照抄他人的地址。普通任务使用通用 ADB；自动关闭模拟器目前仅支持能唯一识别的 MuMu 实例。
3. 打开 MMN“设置 → 连接设置”。选择模拟器附带的 `adb.exe`，也支持 `HD-adb.exe`、`nox_adb.exe`；留空可尝试自动查找。Windows ZIP 自带 Python、Qt、MaaFramework 和 OCR，但 **不附带 ADB**。
4. 填写目标实例地址，例如 `127.0.0.1:端口`，将“端口”替换为实际数字。USB 设备使用实际序列号。多开时逐个核对，避免操作错误账号。
5. “检测设备”只列出 ADB 已发现的设备，不保证主动连接新地址。TCP 地址尚未连接时，勾选“自动连接指定地址”，再点“连接与截图测试”；关闭自动连接时只使用已连接设备。USB 设备通常无需开启该项。
6. 确认测试显示成功，预览是目标实例，尺寸与游戏画面正确。首次连接若设备显示“未授权”，在设备上确认调试授权后重试。检测到设备不等于截图测试通过。

开始任务时仍会重新检查连接。修改路径、地址或实例后重新测试，不依赖旧的通过提示。

## 4. 选择任务与执行

每日任务页包含[README 所列全部 14 个正式任务组](../README.md#功能)。默认全不选；按需勾选，程序按固定顺序运行。建议首次只选“启动”，确认页面与账号后再逐项启用其他任务。运行中不要手动点击游戏、切换账号或实例。

齿轮提供相应任务参数：签到补签及费用档位、限时活动签到、奖励领取的邮箱/每日任务及好友邮件、联盟图书馆三次整理、评选赛投票次数与参赛、体力处理件数、谜之屋金币抽取及次数上限。补签涉及钻石，需要授权识别出的实际费用；图书馆三次整理包含两次金币整理。织梦人可能购买金币服装；服装店会购买 3 件服装；分解重构会分解“无用途”服装。免费默认不代表所有任务都无金币消费，运行前逐项检查。

点击“开始任务”后可查看进度、状态、耗时和日志。“停止”需等待当前操作安全返回，不能保证立即中断。默认单项失败即停止；开启“任务失败后继续下一项”后仍需成功恢复主页，断连或恢复失败会停止。重试失败项、继续未完成任务前，先核对实际奖励与消费结果；不要通过删除运行保护记录强行重试。详见[运行记录](run_records.md)。

仅查看流程可在“设置 → 运行设置”打开“离线演练”，不连接 ADB、不启动或关闭模拟器，也不会真的完成游戏任务。退出演练前核对任务、费用开关与连接设置。

## 5. 定时、自动启动与关闭模拟器

在“设置 → 定时与启动”设置小时和分钟，再开启“启用每日定时执行”。GUI 只设置一个每日时刻，按电脑本地时间运行当前勾选任务，并自动补上“启动游戏”。没有勾选任务、程序忙碌或正在检测连接时跳过。电脑关机、休眠或退出 MMN 时不会运行，不唤醒电脑、不补跑。

MMN 可最小化，但必须保持运行；**不包含 Windows 开机自启服务**。同一分钟防重仅保留在进程内，该分钟重启可能再次触发，避免此时重启。需要登录或验证码时仍须手动处理。

“设备未就绪时自动启动模拟器”默认关闭。使用前选择模拟器启动 EXE，按需填多开参数，核对 ADB 地址。MuMu 选择 `MuMuNxMain.exe` 或 `mumu-cli.exe`，同目录需有 `mumu-cli.exe`；参数留空时按本机 ADB 地址唯一匹配实例，匹配失败不会随意启动其他实例。手动开始任务也会使用此设置，不能把它理解为只对定时生效。

“全部任务完成后关闭模拟器”在“设置 → 运行设置”单独开启；还需在“定时与启动”选择 MuMu 启动程序，无需同时开启自动启动。仅全部真实任务成功、运行环境释放完成且未请求停止后，才请求正常关闭本次地址唯一对应的 MuMu 实例，MMN 窗口保留。失败、部分成功、停止或演练不会关闭；请求成功也不保证模拟器已经退出，请看日志与实际窗口。

## 6. 更新、备份与配置迁移

本版已公开。内置更新器配置的目标是 `ccr-39/MaaMiracleNikki-Public`，只匿名检查稳定版，不自动安装 Pre-release；本测试版需从本教程上方的 Release 链接手动下载。软件更新设置可关闭启动检查，也可手动检查、下载与确认安装；源码运行仅检查与下载，不替换源码。

更新前退出 MMN，备份整个 `userdata` 和旧完整程序。将新版**完整** `MaaMiracleNikki` 目录内容覆盖到旧 EXE 所在目录，保留原 `userdata`；不要误套一层同名目录，也不要只替换 EXE。同目录保留设置，新目录会生成默认配置。不要混用不同版本的 `_internal`。

迁移到新目录时先关闭两边程序、备份目标数据，再复制 `userdata\config\gui.json` 到新 EXE 同目录的对应位置；换电脑后需重新核对路径和地址。若需要保留消费保护记录，应核对账号和实例后迁移整个 `userdata`，不能仅迁移勾选状态后认为保护记录仍在。

仅当前安装目录旧 `config\gui.json` 可被自动迁移，保留原文件和字节备份，已有新配置优先。共享 `%LOCALAPPDATA%\MaaMiracleNikki` 或 `MaaMiracleNikki-Public` 的数据不会自动读取或删除；如确需迁移，在退出后手动复制。细节见[配置迁移](CONFIGURATION_MIGRATION.md)。

## 7. 常见问题

| 问题 | 检查方法 |
| --- | --- |
| 双击无窗口或缺少 DLL | 完整解压，保留 `_internal` 与更新器；查 `userdata\logs\startup.log` 和 `console.log`。核对文件哈希及安全软件隔离记录，不随意从第三方下载 DLL。当前未完成所有干净机器兼容性验收。 |
| 找不到 ADB 或没有设备 | 手动选择模拟器提供的 ADB，确认调试开关、实例、实际端口；TCP 连接按需开启自动连接后测试。不要将示例端口当作实际配置。 |
| `offline` / `unauthorized` | 确认目标模拟器已启动、调试授权已接受；关闭任务后重新测试。多套 ADB 可能冲突，优先统一使用模拟器提供的版本。 |
| 截图成功但识别或点击失败 | 核对国服中文、分辨率、页面、活动弹窗及网络。游戏更新可能需要适配；不要反复运行涉及消费的任务。 |
| 任务没有自动勾选 | 首次启动的默认行为。手动选取并等待自动保存。 |
| 定时未执行 | 检查开关、电脑本地时间、是否有勾选任务、程序是否仍运行或忙碌；不会补跑。 |
| 无法关闭模拟器 | 当前仅支持地址唯一匹配的 MuMu；检查运行设置开关、启动程序路径和全部成功条件，查看警告日志。 |
| 更新后设置丢失 | 确认启动的是原 EXE 目录，而非新解压的嵌套目录。退出后从备份迁移，不要覆盖仍在运行的配置。 |
| 更新页未找到新版本 | Pre-release 不参与稳定版更新；仓库权限、网络或限流也会影响查询。以 Releases 页面为准。 |

遇到问题请先查看[已有 GitHub Issues](https://github.com/ccr-39/MaaMiracleNikki-Public/issues)；如未找到相同问题，可[新建 Issue](https://github.com/ccr-39/MaaMiracleNikki-Public/issues/new)，注明版本、模拟器、分辨率和复现步骤。提交反馈需登录 GitHub。日志、配置和截图可能包含昵称、账号、设备地址及个人路径，先脱敏；不要上传整个 `userdata`、原始账号截图、ADB 密钥或完整工作目录。
